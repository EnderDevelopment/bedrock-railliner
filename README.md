# Minecraft Bedrock Train Mod

Bedrock Railliner is a Minecraft Bedrock train mod and add-on for Pocket Edition and Bedrock Edition that adds a rideable passenger train using standard vanilla Bedrock Minecart Rails, with eight seats and interior handrails.

## Install

1. Keep the `Train_Behavior_Pack` and `Train_Resource_Pack` folder names and leave each `manifest.json` at the root of its pack.
2. For an importable installation, zip the contents of each pack folder so that `manifest.json` is at the root of each archive.
3. Rename the archives to `Train_Behavior_Pack.mcpack` and `Train_Resource_Pack.mcpack`.
4. Open both `.mcpack` files with Minecraft Bedrock to import them.
5. Create or edit a world and activate both the Bedrock Rail Train Behavior Pack and Bedrock Rail Train Resources pack.

For local development, copy the two pack folders into the matching `development_behavior_packs` and `development_resource_packs` folders inside the Bedrock `com.mojang` data directory.

## Use

1. Build a track with standard Bedrock Rails, Powered Rails, Detector Rails, or Activator Rails.
2. Stand on a rail and run:

```text
/summon bedrockrail:rail_train ~ ~ ~
```

3. Interact with the train to board it.
4. Use powered rails with a redstone power source to move the train around the track.
5. The train provides eight passenger seats and includes visible interior handrails along both sides.

The add-on uses vanilla Bedrock rail movement and does not replace or add custom rail blocks. It targets Bedrock format version 1.21.0 and does not use Java Edition files, loaders, or APIs.
